# مجلس النماذج — دليل الدمج والتشغيل

تمت إضافة وضع «مجلس النماذج» إلى قائمة Agent Mode في AiWay.

## الاستخدام
1. افتح محادثة جديدة واختر «✦ مجلس النماذج».
2. افتح «تشكيل الفريق». اختر من عضوين إلى أربعة؛ لكل عضو مزود وموديل ودور ومهمة مستقلة.
3. اضغط «تحميل موديلات المزود» ثم اكتب/اختر Model ID متاحًا في حسابك. يمكن استخدام الموديل نفسه بأدوار مختلفة.
4. اختر 1–3 جولات ومنسق الخلاصة. احفظ الفريق، ثم أرسل المهمة من مربع المحادثة.
5. تابع المساهمات في البطاقات القابلة للفتح، واستخدم زر الإيقاف المعتاد عند الحاجة. «تصدير النقاش» ينزّل سجل آخر جلسة كملف Markdown.

كل عضو يرى مساهمات الأعضاء الذين سبقوه، وفي الجولات التالية يراجع النقاش السابق. بعد الجولات يقدم المنسق خلاصة، مع نقاط الاتفاق والخلاف وخطوات التنفيذ. عدد الطلبات الأساسي = عدد الأعضاء × عدد الجولات + طلب الخلاصة. إعادة المحاولة التلقائية قد تضيف طلبات.

الإعدادات وسجل آخر جلسة محفوظان لكل محادثة في IndexedDB. تظل نسخ الجلسات المكتملة أيضًا داخل رسائل الرد عند تصدير بيانات الموقع. تحديث الصفحة لا يستأنف الطلبات المدفوعة تلقائيًا. النقاش نصي؛ الصق النصوص المطلوبة في الرسالة. الأدوات والبحث وتعديل الملفات غير مفعلة في هذا الوضع.

## العلاقة مع delegate-skills
المصدر: https://github.com/amElnagdy/delegate-skills

المستودع الأصلي ينسق وكلاء برمجة يعملون عبر CLI على working tree، ويصدر نتيجة للمراجعة قبل commit. ليس SDK للنقاش داخل المتصفح. هذه الإضافة تطبيق أصلي لفكرة توزيع الأدوار → التنفيذ → المراجعة → الخلاصة، باستخدام API النماذج الموجودة في AiWay. لم تُنسخ سكربتات المستودع أو تُنفذ تعليماته ولم تُضف تبعية npm له.

التكامل المباشر مستقبلًا يحتاج عامل تنفيذ موثوقًا خارج Serverless: يتلقى brief محددًا، ويختار relay من قائمة سماح ثابتة، ويعمل في checkout معزول، ويعيد result.json وdiff للواجهة. يجب إبقاء مراجعة التغييرات والموافقة على commit منفصلتين. لا يكفي تشغيل shell من المتصفح أو تحويل اسم الموديل إلى أمر. هذا العامل ليس ضمن النسخة الحالية.

## التشغيل
استخدم طريقة نشر المشروع المعتادة على Vercel مع Node 24. احتفظ بقيم المزودين الموجودة في Environment Variables كما في .env.example. لا توجد أسرار جديدة ولا route إضافي. المزودون المتاحون للمجلس: OpenCode Zen، Gemini، OpenRouter، B.ai، New API. Hermes غير مضمّن لأنه قد يشغّل أدوات داخلية مستقلة، بينما المجلس هنا نصي.

- الواجهة ومحرك المجلس: assets/delegate.js + قسم Delegate Council في assets/app.js.
- البطاقات والتنسيق: index.html وassets/app.css.
- نفس /api/models لتحميل القوائم، ونفس /api/ai للمحادثات، مع حفظ الأسرار على الخادم والمصادقة الحالية ومحاسبة الاستخدام والبث والإلغاء.
- إخفاق عضو يوقف الجلسة ويحفظ المساهمات السابقة بدل عرض خلاصة مصطنعة. بعد إصلاح الإعدادات يمكن إرسال المهمة مجددًا (جلسة جديدة كاملة، وقد تعيد التكاليف).
- السياق محدود بواسطة مدير السياق الموجود، ومساهمة كل عضو المرسلة للجولات التالية محدودة بآخر 10000 حرف. لذلك يفضل طلب ردود مركزة.

تم أيضًا إصلاح اختبار Exa لاستخدام fileURLToPath على Windows، وتحديث قائمة الديون القديمة في اختبار tool-registry بعد تحقق وجود القراءات الفعلية، وإضافة ملف harness-runtime الذي كان مذكورًا في package.json لكنه مفقود من الأرشيف.
