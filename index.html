الإعدادات

Model واحد لكل محادثة. الإعدادات العامة تحفظ محليًا، أما مفاتيح الـAPI فتبقى داخل Vercel Environment Variables ولا تصل للمتصفح.

نسخة Vercel: مفاتيح OpenCode Zen وHermes وGemini وOpenRouter وJina تُقرأ فقط داخل Serverless Functions. Hermes يحتاج HERMES_BASE_URL قابلًا للوصول من Vercel، وليس 127.0.0.1 على جهازك.

الموديل

تظهر بعد تحديث موديلات Hermes.
Native Runs يستخدم /v1/runs وSSE الخاص بـHermes ويعرض نشاط أدواته وSubagents. AiWay Loop يبقي تنفيذ الأدوات داخل المتصفح كما كان.

API Secrets

تُدار مفاتيح المزودين من Vercel → Project → Settings → Environment Variables. لا تضع مفاتيح المزودين داخل هذا الملف.
لو ضبطت APP_ACCESS_KEY في Vercel، أدخله هنا لكل جلسة لحماية استهلاك مفاتيح الـAI من الزوار. لا يتم حفظه في IndexedDB.

GitHub + Vercel Publisher

النشر يتم من السيرفر فقط. مفاتيح GitHub وVercel لا تصل للمتصفح. أدخل مفتاح النشر الشخصي في كل جلسة للسماح بإنشاء Repository وVercel Project جديدين.
هذا المفتاح لا يُحفظ في IndexedDB؛ يبقى في ذاكرة الصفحة فقط حتى تغلقها أو تعيد تحميلها.

Smart Context & Model Router

Context Optimizer: ON دائمًا — يفهرس ملفات المشروع ويختار مقاطع الكود الأصلية المرتبطة بالطلب فقط، ثم يستخدم project_search/artifact_read عند الحاجة بدل إرسال المشروع كاملًا في كل رسالة.
هذا هو السقف الذي تختاره أنت للسياق. حدود الموديل المعروضة أدناه معلومات فقط ولا تغيّر هذه القيمة تلقائيًا.
Auto Router لا ينشئ Agent إضافي؛ يختار موديلًا واحدًا لنفس الـAgent قبل بدء الطلب.

Search Auto Router
