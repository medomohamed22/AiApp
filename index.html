الإعدادات

Model واحد لكل محادثة. الإعدادات العامة تحفظ محليًا، أما مفاتيح الـAPI فتبقى داخل Vercel Environment Variables ولا تصل للمتصفح.

نسخة Vercel: مفاتيح OpenCode وHermes وGemini وOpenRouter وJina تُقرأ فقط داخل Serverless Functions. Hermes يحتاج HERMES_BASE_URL قابلًا للوصول من Vercel، وليس 127.0.0.1 على جهازك.

الموديل

API Secrets

تُدار من Vercel → Project → Settings → Environment Variables. لا تضع أي مفتاح داخل هذا الملف.

GitHub + Vercel Publisher

النشر يتم من السيرفر فقط. مفاتيح GitHub وVercel لا تصل للمتصفح. أدخل مفتاح النشر الشخصي في كل جلسة للسماح بإنشاء Repository وVercel Project جديدين.
هذا المفتاح لا يُحفظ في IndexedDB؛ يبقى في ذاكرة الصفحة فقط حتى تغلقها أو تعيد تحميلها.
غير مختبر
Secrets Manager للموقع المنشور
يعرض أسماء Environment Variables فقط. القيم السرية لا تُقرأ ولا تُعرض للنموذج.
انشر المشروع أولًا أو اضغط تحديث.

Agent Runtime

يُرسل كـ max_tokens إلى OpenRouter و maxOutputTokens إلى Gemini. خفّضه إذا كانت أرصدة OpenRouter لا تكفي.

Smart Context & Model Router

Auto Router لا ينشئ Agent إضافي؛ يختار موديلًا واحدًا لنفس الـAgent قبل بدء الطلب.

Search Auto Router

في Auto، الطلبات البصرية مثل الشكل والتصميم والصور والألوان والواجهات تستخدم بحث الويب + الصور، بينما المعلومات العادية تستخدم Web فقط. الصور المختارة تُرسل للموديل كرؤية عندما يدعم المزود ذلك.
